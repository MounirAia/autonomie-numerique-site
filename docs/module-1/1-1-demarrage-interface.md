# 1.1 — Démarrage et interface Windows

## 1) Démarrage et fermeture

<div className="img-row">
  <div><img src="/img/module-1/1.1-power-button.png" alt="Menu Démarrer avec le bouton d'alimentation encerclé" /></div>
  <div><img src="/img/module-1/1.1-restart-shutdown.png" alt="Menu Démarrer avec les options Arrêter et Redémarrer encadrées" /></div>
</div>

- **Allumer** : appuyer sur le bouton d'alimentation (souvent sur le côté ou en haut du clavier)
- **Attendre** le chargement complet avant d'ouvrir des applications
- **Éteindre correctement** : Menu Démarrer → icône ⏻ → **Arrêter** *(ne jamais fermer le couvercle pour éteindre)*
- **Redémarrer** : Menu Démarrer → icône ⏻ → **Redémarrer** *(à faire quand l'ordinateur est lent ou après une mise à jour)*

## 2) Interface Windows

<div className="img-row">
  <div><img src="/img/module-1/1.1-interface-windows.png" alt="Bureau Windows 11 avec 4 flèches numérotées" /></div>
  <div><img src="/img/module-1/1.1-folder.png" alt="Fenêtre avec les 3 boutons de contrôle encadrés en rouge" /></div>
</div>

| Élément | Description |
|---|---|
| **Bureau** | Espace principal avec icônes et fond d'écran |
| **Barre des tâches** | Barre en bas : applications ouvertes, horloge, notifications |
| **Bouton Démarrer** | Logo Windows en bas à gauche — ouvre le menu principal |
| **Fenêtres** | Chaque application s'ouvre dans une fenêtre : réduire **(—)**, agrandir **(□)**, fermer **(✕)** |
