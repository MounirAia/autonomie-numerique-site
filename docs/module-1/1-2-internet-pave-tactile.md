# 1.2 — Internet et pavé tactile

## 3) Se connecter à Internet

![Panneau Wi-Fi dans la barre des tâches Windows 11](/img/module-1/1.2-wifi.png)

1. Cliquer sur l'icône **Wi-Fi** en bas à droite de la barre des tâches
2. Choisir son réseau dans la liste
3. Entrer le **mot de passe Wi-Fi** si demandé
4. Ouvrir un navigateur : **Chrome**
5. Taper un site dans la barre d'adresse (ex. : `google.ca`) ou faire une recherche directement

> **Astuce :** L'icône Wi-Fi ressemble à des petites vagues. Si elle a un X rouge, c'est qu'on n'est pas connecté.

---

## 4) Pavé tactile (Touchpad)

![Gestes du pavé tactile : clic, double clic, clic droit, défilement](/img/module-1/1.2-touchpage.png)

| Geste | Action |
|---|---|
| **1 doigt — appuyer une fois** | Sélectionner un élément |
| **1 doigt — appuyer deux fois vite** | Ouvrir un fichier ou une application |
| **2 doigts — appuyer** | Clic droit (affiche un menu d'options) |
| **2 doigts — glisser vers le bas/haut** | Faire défiler la page |

> **Astuce :** Si le pavé tactile n'est pas confortable, brancher une souris USB — les deux fonctionnent en même temps.
