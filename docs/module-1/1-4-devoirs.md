# 1.4 — Devoirs

## Devoir 1 — Gestion de base

1. Créer un dossier sur le bureau, le nommer **Test**
2. Créer un fichier texte dans ce dossier, le nommer **Test.txt**
3. Ouvrir le fichier texte, écrire `Bonjour, ceci est un test.` et sauvegarder
4. Renommer le fichier texte en **Test2.txt**
5. Copier le fichier texte et le coller dans le même dossier, le nommer **Test3.txt**
6. Supprimer le fichier **Test3.txt** et vider la corbeille

---

## Devoir 2 — Dossiers et sous-dossiers

1. Créer un dossier sur le bureau, le nommer **ProjetTest**
2. Créer deux sous-dossiers dans **ProjetTest** : **Dossier-A** et **Dossier-B**
3. Dans **Dossier-A**, créer trois fichiers texte : **note1.txt**, **note2.txt**, **note3.txt**
4. Déplacer **note3.txt** de **Dossier-A** vers **Dossier-B**
5. Copier **note1.txt** de **Dossier-A** vers **Dossier-B**
6. Renommer **note1.txt** dans **Dossier-B** en **note1-copie.txt**
7. Supprimer **note2.txt** et vider la corbeille
