# 10.1 — Le magasin d'applications

Le **magasin d'applications** est l'endroit sur votre téléphone où vous pouvez trouver et télécharger des applications gratuitement ou en les achetant.

- **iPhone :** App Store (icône bleue avec un « A »)
- **Android :** Google Play Store (icône triangulaire colorée)

---

## Chercher une application

**Par nom :**
1. Ouvrir le magasin d'applications
2. Appuyer sur la **loupe** (recherche)
3. Taper le nom de l'application (ex. : `Gmail`, `La Presse`, `Chrono`)
4. Les résultats s'affichent — appuyer sur l'application souhaitée

**Par catégorie :**
1. Dans le magasin, naviguer vers l'onglet **Catégories** ou **Explorer**
2. Choisir une catégorie (ex. : Actualités, Productivité, Navigation)
3. Parcourir les applications proposées

---

## Reconnaître les publicités

Dans les résultats de recherche, certaines applications sont des **publicités payées** — elles apparaissent en premier avec la mention **Annonce** ou **Sponsored** en petit.

Ces applications ne sont pas forcément les meilleures. Regarder plus bas dans les résultats pour trouver ce que vous cherchez vraiment.

---

## Lire la fiche d'une application

Avant de télécharger une application, examiner sa fiche :

| Information | Ce que ça indique |
|---|---|
| **Nom** | Le nom exact de l'application |
| **Développeur** | La compagnie ou personne qui a créé l'application |
| **Note** | La note moyenne des utilisateurs (ex. : 4,5 / 5) |
| **Nombre d'avis** | Plus il y a d'avis, plus la note est fiable |
| **Description** | Ce que fait l'application |
| **Captures d'écran** | À quoi ressemble l'application à l'intérieur |
| **Avis des utilisateurs** | Commentaires de personnes qui ont téléchargé l'application |

> **Conseil :** Avant de télécharger, vérifier que le développeur est connu et que la note est bonne (au-dessus de 4 / 5).

---

## Télécharger une application

1. Sur la fiche de l'application, appuyer sur le bouton **Obtenir** (iPhone) ou **Installer** (Android)
2. Confirmer avec Face ID, Touch ID ou le mot de passe du compte (si demandé)
3. L'application se télécharge et s'installe automatiquement
4. Une fois installée, elle apparaît sur l'écran d'accueil ou dans la liste des applications
