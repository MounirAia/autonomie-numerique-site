# 10.2 — Messenger

**Messenger** est l'application de messagerie de Facebook. Elle permet d'envoyer des messages texte, des photos, des vidéos, et de passer des appels vidéo — sans avoir à payer pour les textos.

---

## Installer et se connecter

1. Ouvrir le magasin d'applications (App Store ou Google Play)
2. Rechercher **Messenger** et appuyer sur **Installer**
3. Ouvrir l'application
4. Se connecter avec :
   - Un **compte Facebook** (si vous en avez un), ou
   - Un **numéro de téléphone** (si vous n'avez pas de compte Facebook)
5. Entrer le code de confirmation envoyé par texto

---

## Écrire un message à quelqu'un

1. Appuyer sur l'icône **crayon** (nouveau message) en haut à droite
2. Taper le **nom** de la personne dans la barre de recherche
3. Sélectionner la bonne personne dans les résultats
4. Écrire le message dans le champ en bas et appuyer sur la **flèche** pour envoyer

---

## Fonctions principales

| Fonction | Comment faire |
|---|---|
| Envoyer un message texte | Taper dans le champ de texte → appuyer sur la flèche d'envoi |
| Envoyer une photo | Appuyer sur l'icône **photo** (à gauche du champ de texte) → choisir dans la galerie |
| Envoyer une vidéo | Appuyer sur l'icône **photo** → choisir une vidéo dans la galerie |
| Appel vidéo | Ouvrir la conversation → appuyer sur l'icône **caméra** en haut à droite |
| Appel audio | Ouvrir la conversation → appuyer sur l'icône **téléphone** en haut à droite |
