# 10.3 — Devoirs

---

## Devoir 1 — Explorer le magasin d'applications

1. Ouvrir le magasin d'applications sur votre téléphone (App Store ou Google Play)
2. Trouver **3 applications différentes** qui vous intéressent (n'importe quelle catégorie)
3. Pour chaque application, noter :
   - Le **nom** de l'application
   - Le **développeur**
   - La **note** (étoiles)
   - Une courte **description** de ce qu'elle fait
   - Le **lien** vers sa page dans le magasin
4. Envoyer ces informations au formateur dans **un seul courriel** via Gmail

**Exemple de présentation dans le courriel :**

> Application 1 : La Presse — Groupe La Presse — 4,7 / 5
> Actualités québécoises et canadiennes
> https://apps.apple.com/...
>
> Application 2 : Chrono — ... — 4,5 / 5
> ...

---

## Devoir 2 — Télécharger une application

Télécharger **une** des applications suivantes sur votre téléphone :

- **La Presse** — actualités du Québec
- **Journal de Montréal** — actualités du Québec
- **Chrono** — horaires d'autobus et métro de Montréal (STM)

Après avoir téléchargé l'application :
1. L'ouvrir pour vérifier qu'elle fonctionne
2. Envoyer un courriel au formateur pour confirmer l'application téléchargée et dire ce que vous en pensez en quelques mots
