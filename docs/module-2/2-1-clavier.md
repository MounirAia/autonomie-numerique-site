# 2.1 — Le clavier

## Les touches principales

| Touche | Rôle |
|---|---|
| **Lettres / chiffres** | Taper du texte |
| **Barre d'espace** | Ajouter un espace |
| **Entrée** | Valider ou aller à la ligne |
| **Backspace** | Effacer la lettre à gauche du curseur |
| **Delete** | Effacer la lettre à droite du curseur |
| **Shift** | Écrire une majuscule (tenir appuyé + lettre) |
| **Caps Lock** | Activer/désactiver les majuscules permanentes |
| **Tab** | Passer au champ suivant dans un formulaire |
| **Échap (Esc)** | Annuler ou fermer une fenêtre |
| **Flèches** | Déplacer le curseur dans le texte |
