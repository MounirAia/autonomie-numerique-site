# 2.2 — Chercher sur YouTube

## Quand chercher un tutoriel ?

Quand vous êtes bloqué sur une tâche, YouTube peut être utile : certains créateurs filment des démonstrations étape par étape. Ce n'est pas toujours la meilleure source, mais c'est un bon point de départ pour les tâches visuelles.

## Comment formuler la recherche

La recette simple : **`comment faire` + le sujet**

| Ce que vous voulez apprendre | Quoi taper sur YouTube ou Google |
|---|---|
| Créer un CV dans Word | `comment faire un CV Word` |
| Envoyer un courriel avec pièce jointe | `comment envoyer pièce jointe Gmail` |
| Copier-coller du texte | `comment copier coller Windows` |
| Faire une capture d'écran | `comment capturer écran Windows 11` |

## Comment évaluer un tutoriel

Avant de suivre un tutoriel, vérifier ces 3 points :

| Indicateur | Ce qu'il signifie |
|---|---|
| Nombre de likes élevé | Le contenu est apprécié |
| Beaucoup de vues | Populaire et probablement fiable |
| Date récente | L'interface correspond à ce que vous voyez |

> **Astuce :** Si le tutoriel est trop rapide ou trop vieux, cherchez-en un autre.
