# 2.3 — ChatGPT : premiers pas

## C'est quoi une IA conversationnelle ?

**ChatGPT** est un assistant intelligent avec qui on peut avoir une conversation écrite. On lui pose une question ou on lui donne une tâche, et il répond avec du texte clair.

**Ce qu'on peut lui demander :**
- Expliquer quelque chose simplement (ex. : « Explique-moi c'est quoi un REER »)
- Rédiger ou corriger un texte (ex. : lettre de motivation, courriel)
- Résoudre un problème informatique étape par étape
- Faire une liste, un tableau, un résumé

## Accéder à ChatGPT

1. Ouvrir Chrome et aller sur **[chatgpt.com](https://chatgpt.com)**
2. Cliquer sur **« Commencer »** ou **« Stay logged out »** pour utiliser sans compte

> **Remarque :** On peut utiliser ChatGPT **sans créer de compte** (mode invité). C'est plus simple pour commencer.

## Tour de l'interface

| Élément | Description |
|---|---|
| **Zone de saisie** (en bas) | Taper votre question ou demande ici |
| **Bouton envoi** (↵ ou →) | Envoyer le message à l'IA |
| **Historique** (colonne gauche) | Retrouver les conversations passées (si connecté) |
| **Nouveau chat** (+ en haut) | Démarrer une nouvelle conversation |
