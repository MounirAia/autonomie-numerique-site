# 2.3 — Devoirs

## Devoir 1 — Pratiquer la frappe

1. Aller sur [monkeytype.com](https://monkeytype.com/)
2. Choisir le mode **quotes**
3. Choisir la langue **français**
4. Taper pendant 5 minutes — essayer de regarder le clavier le moins possible

---

## Devoir 2 — Jeu d'évasion

Pratique : **Ctrl + C**, **Ctrl + V**, **Ctrl + F**

**Étape 1.** Copier le code ci-dessous avec **Ctrl + C** :

```
aHR0cHM6Ly9hdXRvbm9taWUtbnVtZXJpcXVlLmNhL3NlY3JldA==
```

**Étape 2.** Coller le code dans le décodeur avec **Ctrl + V**, puis cliquer sur **Décoder** — le résultat sera un lien cliquable :
