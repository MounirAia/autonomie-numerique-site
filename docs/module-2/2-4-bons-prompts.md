# 2.4 — Rédiger de bons prompts

## C'est quoi un prompt ?

Un **prompt**, c'est le message que vous envoyez à l'IA. Plus il est clair et précis, meilleure sera la réponse.

## Mauvais vs bon prompt

| ❌ Prompt vague | ✅ Prompt précis |
|---|---|
| `CV` | `Fais-moi un CV pour un poste de préposé aux bénéficiaires. J'ai 3 ans d'expérience en CHSLD.` |
| `Lettre` | `Écris une lettre de motivation courte pour postuler comme caissier chez IGA. Je suis ponctuel et j'aime le service à la clientèle.` |
| `Explique-moi` | `Explique-moi en termes simples c'est quoi un REER et pourquoi c'est utile.` |
| `Aide-moi` | `Je dois envoyer un courriel professionnel à mon employeur pour demander une journée de congé. Écris-moi un exemple court et poli.` |

**La règle d'or :** Donnez le **contexte** (qui vous êtes, pourquoi), la **tâche** précise, et le **format** souhaité.

## Rendre votre prompt plus clair avec le Markdown

En ajoutant des tirets `-` ou des titres `#` **dans votre question**, vous aidez l'IA à comprendre exactement ce que vous cherchez — comme si vous lui faisiez une liste de points à couvrir.

**Exemple — du prompt vague au prompt structuré :**

| | Prompt |
|---|---|
| **Avant** | `Explique-moi les vitamines` |
| **Après** | `# Vitamines`<br/>`Explique-moi les vitamines :`<br/>`- C'est quoi une vitamine`<br/>`- Pourquoi c'est important pour la santé`<br/>`- Les principales sources alimentaires` |

Le **prompt vague** laisse l'IA décider quoi inclure — le résultat peut être trop général ou passer à côté de ce que vous voulez vraiment.

Le **prompt structuré** lui indique précisément les trois points à expliquer : elle suit votre liste, point par point.
