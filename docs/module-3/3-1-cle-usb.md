# 3.1 — Clé USB : transférer des fichiers

## C'est quoi une clé USB ?

Une **clé USB** est un petit périphérique de stockage portable. Elle permet de transporter des fichiers d'un ordinateur à l'autre sans passer par Internet.

---

## Brancher la clé USB

1. Repérer le **port USB** sur l'ordinateur (port rectangulaire sur le côté ou à l'arrière)
2. Insérer la clé USB dans le port
3. Attendre quelques secondes — une **notification** apparaît en bas à droite
4. L'explorateur de fichiers peut s'ouvrir automatiquement

---

## Ouvrir la clé USB

1. Ouvrir l'**Explorateur de fichiers** (<kbd>Windows</kbd> + <kbd>E</kbd>)
2. Dans le panneau de gauche, repérer la clé USB sous **Ce PC**
3. Double-cliquer pour l'ouvrir

---

## Copier un fichier vers la clé USB

1. Naviguer jusqu'au fichier à transférer (ex. : dans **Documents**)
2. Faire un **clic droit** sur le fichier → **Copier**
3. Ouvrir la clé USB dans l'Explorateur
4. Faire un **clic droit** dans un espace vide → **Coller**

---

## Copier un fichier depuis la clé vers l'ordinateur

1. Ouvrir la clé USB dans l'Explorateur
2. Faire un **clic droit** sur le fichier → **Copier**
3. Naviguer jusqu'au dossier de destination (ex. : **Bureau** ou **Documents**)
4. Faire un **clic droit** → **Coller**

---

## Éjecter la clé correctement

1. Repérer l'icône **clé USB** dans la barre des tâches (en bas à droite, parfois cachée dans les icônes ^)
2. Cliquer dessus → **Éjecter [nom de la clé]**
3. Attendre le message *« Vous pouvez retirer votre périphérique »*
4. Retirer la clé USB en toute sécurité
