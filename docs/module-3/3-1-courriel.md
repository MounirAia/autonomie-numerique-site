# 3.1 — Envoyer un courriel et joindre un fichier

## Objectif

Rédiger un courriel clair et y joindre un fichier (photo, document, capture d'écran).

---

## Étapes — Envoyer un courriel (Gmail)

1. Ouvrir Gmail dans le navigateur.
2. Cliquer sur **Nouveau message** (en haut à gauche).
3. Dans le champ **À**, entrer l'adresse du destinataire.
4. Dans le champ **Objet**, écrire un sujet clair (ex. : *Devoir module 3*).
5. Rédiger un message court et poli dans la zone de texte.
6. Cliquer sur **Envoyer**.

---

## Joindre un fichier

1. Dans la fenêtre du message, cliquer sur l'icône **trombone** (en bas).
2. Naviguer jusqu'au fichier voulu (photo, document, capture d'écran).
3. Cliquer sur **Ouvrir** — le fichier s'ajoute au message.
4. Vérifier que la pièce jointe apparaît, puis cliquer sur **Envoyer**.

---

## Modèle de message

> **Objet :** Devoir module 3
>
> Bonjour,
>
> Je vous envoie mon devoir du module 3 en pièce jointe.
>
> Merci et bonne journée.

## Trouver une photo sur Google

1. Aller sur **Google Images** : [images.google.com](https://images.google.com).
2. Chercher un sujet (ex. : *chien*, *fleur*).
3. Cliquer sur une photo, puis sur **Télécharger l'image** (clic droit → *Enregistrer l'image sous...*).
4. Choisir un dossier (ex. : *Téléchargements*), puis cliquer sur **Enregistrer**.

---

## Prendre une capture d'écran

| Raccourci | Résultat |
|---|---|
| **Windows + Maj + S** | Sélectionner une zone à capturer |
| **Windows + Imp écran** | Capturer tout l'écran (sauvegardé dans *Images/Captures d'écran*) |

Après la capture, l'image est enregistrée automatiquement dans le dossier **Images → Captures d'écran**.
