# 3.2 — Courriel professionnel et pièces jointes

## Modèle général

Utiliser ce modèle comme point de départ pour n'importe quel courriel professionnel :

```
Bonjour [Nom],

J'espère que vous allez bien.

Je me permets de vous écrire concernant [explique brièvement].
J'aimerais m'assurer d'avoir bien compris / avoir votre avis.

[Ajoute ici les détails si nécessaire.]

Pourriez-vous, s'il vous plaît, me préciser [ta question] ?

Merci beaucoup pour votre temps et votre aide.

Cordialement,
[Ton nom]
```

---

## Exemple concret — Suivi de candidature

Après avoir envoyé un CV, voici comment faire un suivi professionnel :

**Objet**: Suivi de candidature — Poste de [nom du poste]

```
Bonjour [Nom],

J'espère que vous allez bien.

Je me permets de vous recontacter concernant ma candidature
pour le poste de [nom du poste], que je vous ai envoyée le [date].

Je voulais simplement faire un suivi afin de savoir si vous aviez
eu l'occasion de la consulter, et si vous aviez besoin
d'informations supplémentaires de ma part.

Je reste bien entendu disponible pour en discuter.

Merci beaucoup pour votre temps et votre considération.

Cordialement,
[Ton nom]
```

---

## Recevoir et télécharger une pièce jointe

1. Ouvrir le courriel reçu
2. Repérer la pièce jointe en bas du message (icône de document)
3. Cliquer sur **Télécharger** (flèche vers le bas)
4. Le fichier se retrouve dans le dossier **Téléchargements**
