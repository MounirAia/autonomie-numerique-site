# 3.5 — Créer un document avec Word

## Accéder à Word en ligne

Word est disponible gratuitement en ligne via un compte Microsoft.

1. Ouvrir Chrome et aller sur **[word.cloud.microsoft](https://word.cloud.microsoft)**
2. Cliquer sur **Se connecter** (ou **Sign in**)
3. Si vous n'avez pas encore de compte : cliquer sur **Créer un compte** et suivre les étapes
4. Une fois connecté, cliquer sur **Nouveau document vide** pour commencer

> **Astuce :** Utiliser l'adresse courriel Gmail ou en créer une nouvelle sur [outlook.com](https://outlook.com) pour s'inscrire à Microsoft.

## Mettre en forme le texte

- **Titre** : sélectionner le texte → choisir **Titre 1** ou **Titre 2** dans les Styles
- **Gras** : sélectionner le texte → <kbd>Ctrl</kbd> + <kbd>B</kbd>
- **Liste à puces** : cliquer sur l'icône ≡ dans le ruban **Accueil**
- **Alignement centré** : <kbd>Ctrl</kbd> + <kbd>E</kbd>

---

## Insérer une image

1. Cliquer sur l'onglet **Insertion**
2. Cliquer sur **Images** → **Ce périphérique**
3. Choisir l'image sur l'ordinateur
4. Cliquer sur **Insérer**

---

## Enregistrer le document

### Format DOCX (modifiable)

Appuyer sur <kbd>Ctrl</kbd> + <kbd>S</kbd> — Word enregistre automatiquement en `.docx`.

> **Astuce :** Enregistrer souvent avec <kbd>Ctrl</kbd> + <kbd>S</kbd> pour ne pas perdre son travail.

### Format PDF (pour envoyer)

1. Cliquer sur **Fichier** → **Enregistrer sous**
2. Choisir l'emplacement (ex. : Bureau ou Documents)
3. Dans le menu **Type**, sélectionner **PDF**
4. Cliquer sur **Enregistrer**
