# 4.2 — Paramètres et notifications

## Ouvrir les paramètres

- **Android** : appuyer sur l'icône **Paramètres** (roue dentée) dans les applications, ou tirer le volet de notifications vers le bas et appuyer sur la roue dentée
- **iPhone** : appuyer sur l'icône **Réglages** (roue dentée grise) sur l'écran d'accueil

---

## Se connecter au Wi-Fi

1. Ouvrir **Paramètres** → **Wi-Fi** (ou **Réseau sans fil**)
2. Activer le Wi-Fi si ce n'est pas déjà fait
3. Choisir le nom du réseau (SSID) dans la liste
4. Saisir le mot de passe Wi-Fi
5. Appuyer sur **Connecter**

> Une fois connecté, le téléphone se reconnecte automatiquement à ce réseau la prochaine fois.

---

## Données mobiles

Les **données mobiles** permettent d'accéder à Internet sans Wi-Fi, en utilisant le forfait cellulaire.

- **Android** : Paramètres → Réseau → Données mobiles (activer/désactiver)
- **iPhone** : Réglages → Données cellulaires (activer/désactiver)

> Désactiver les données mobiles quand on est à la maison et connecté au Wi-Fi permet d'économiser le forfait.

---

## Gérer les notifications

Les notifications sont les alertes qui apparaissent en haut de l'écran.

**Bloquer les notifications d'une application :**

- **Android** : Paramètres → Applications → [nom de l'app] → Notifications → Désactiver
- **iPhone** : Réglages → Notifications → [nom de l'app] → Désactiver « Autoriser les notifications »

---

## Vérifier l'espace de stockage

- **Android** : Paramètres → Stockage
- **iPhone** : Réglages → Général → Stockage iPhone

> Si le téléphone est plein, supprimer des photos, des vidéos ou des applications inutilisées.
