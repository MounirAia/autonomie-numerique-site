# 5.1 — Réseaux sociaux et messagerie

## Facebook

### Créer un compte

1. Ouvrir **[facebook.com](https://www.facebook.com)** ou l'application **Facebook**
2. Cliquer sur **Créer un compte**
3. Remplir : prénom, nom, date de naissance, courriel ou numéro de téléphone
4. Choisir un **mot de passe** sécuritaire
5. Confirmer le compte via le code envoyé par courriel ou texto

### Ce qu'on peut faire sur Facebook

| Action | Comment |
|--------|---------|
| Publier un texte ou une photo | Cliquer sur **Quoi de neuf ?** en haut du fil d'actualité |
| Ajouter un ami | Chercher la personne → cliquer **Ajouter** |
| Réagir à une publication | Cliquer sur **J'aime** (ou maintenir pour voir les autres réactions) |
| Commenter | Cliquer sur **Commenter** sous la publication |
| Partager | Cliquer sur **Partager** pour republier dans son fil |

## Messenger

**Messenger** est l'application de messagerie de Facebook. Elle sert à envoyer des messages texte, des photos, des messages vocaux et à faire des appels vidéo.

### Comment utiliser Messenger

1. Télécharger l'application **Messenger** (App Store ou Google Play)
2. Se connecter avec son compte Facebook
3. Appuyer sur l'icône **crayon** (nouveau message) pour écrire à quelqu'un
4. Taper le nom de la personne, écrire le message, appuyer sur **Envoyer**

### Fonctions principales

| Fonction | Comment |
|----------|---------|
| Envoyer un message texte | Taper dans le champ de texte → appuyer sur la flèche |
| Envoyer une photo | Appuyer sur l'icône **photo** (galerie) |
| Message vocal | Maintenir le bouton **micro** et parler |
| Appel vidéo | Appuyer sur l'icône **caméra** en haut à droite |
| Appel audio | Appuyer sur l'icône **téléphone** en haut à droite |
