# 5.5 — Applications de services du quotidien

Beaucoup de services que tu utilises au quotidien (banque, électricité, téléphone, Internet) ont leur propre **application mobile**. Ces applications permettent de gérer tes comptes sans avoir à te déplacer ou appeler.

---

## Applications bancaires

Chaque banque offre une application pour gérer son argent :

| Banque | Application |
|--------|------------|
| Desjardins | Desjardins |
| Banque Nationale | Banque Nationale |
| TD | TD Canada |
| RBC | RBC Banque en direct |
| BMO | BMO Mobile |
| Banque Laurentienne | BLCDirect |

**Ce qu'on peut faire :**
- Voir le **solde** de ses comptes
- Consulter l'**historique** des transactions
- **Payer** des factures
- **Transférer** de l'argent par Virement Interac

---

## Applications de fournisseurs de services

| Fournisseur | Ce que l'application permet |
|-------------|----------------------------|
| **Hydro-Québec** | Voir sa consommation d'électricité, payer sa facture, signaler une panne |
| **Vidéotron** | Consulter sa facture Internet/téléphone, gérer son forfait |
| **Bell** | Voir sa facture, modifier son forfait, contacter le service à la clientèle |
| **Fizz** | Gérer son forfait mobile, voir sa consommation de données |
| **Telus** / **Koodo** | Consulter et payer sa facture, gérer son forfait |

---

## Comment trouver et installer ces applications

1. Ouvrir **App Store** (iPhone) ou **Google Play** (Android)
2. Taper le nom du service (ex. : « Desjardins », « Hydro-Québec »)
3. Vérifier le nom de l'éditeur (ex. : « Mouvement Desjardins », « Hydro-Québec »)
4. Appuyer sur **Installer**
5. Se connecter avec les identifiants de son compte en ligne
