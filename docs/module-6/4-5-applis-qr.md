# 6.4 — Codes QR

## Désinstaller une application

- **Android** : appui long sur l'icône → **Désinstaller**
- **iPhone** : appui long sur l'icône → **Supprimer l'app**

---

## Lire un code QR

Un **code QR** est un carré noir et blanc qui contient un lien ou une information. On le retrouve sur des affiches, des menus de restaurant, des billets d'événements, etc.

**Comment le scanner :**

1. Ouvrir l'application **Caméra** (pas besoin d'application spéciale)
2. Pointer la caméra vers le code QR — tenir le téléphone stable
3. Un lien ou une notification apparaît en haut de l'écran
4. Appuyer sur la notification pour ouvrir le lien
