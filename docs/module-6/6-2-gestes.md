# 6.3 — Gestes de base pour smartphone

Les smartphones utilisent des gestes tactiles pour naviguer et interagir avec les applications. Voici les gestes de base à connaître pour utiliser votre téléphone efficacement.

---

## Naviguer entre les écrans d'accueil

| Geste | iPhone | Android |
|---|---|---|
| Changer d'écran d'accueil | Balayer gauche ou droite | Balayer gauche ou droite |
| Revenir à l'écran d'accueil | Balayer du bas vers le haut (complètement) | Appuyer sur le bouton **Accueil** |
| Ouvrir le gestionnaire d'apps | Balayer du bas vers le haut et maintenir | Appuyer sur le bouton **Applications récentes** |

---

## Ouvrir les panneaux système

| Action | iPhone | Android |
|---|---|---|
| Centre de contrôle (Wi-Fi, luminosité, volume) | Balayer depuis le coin **haut droit** vers le bas | Balayer depuis le **haut droit** vers le bas |
| Tout le panneau de notifications rapides | — | Balayer une deuxième fois vers le bas |
| Centre de notifications | Balayer depuis le coin **haut gauche** vers le bas | Balayer depuis le **haut gauche** vers le bas |
| Recherche | Balayer vers le bas au **centre** de l'écran d'accueil | Balayer vers le **haut** depuis l'écran d'accueil |

---

## Réorganiser les applications

### iPhone

1. Appuyer sur une zone vide de l'écran d'accueil et **maintenir** → les icônes se mettent à trembler
2. **Déplacer une app** : glisser l'icône vers une autre position ou une autre page
3. **Créer un dossier** : glisser une app sur une autre app
4. **Déplacer plusieurs apps** : commencer à glisser une app, puis appuyer sur d'autres apps avec un autre doigt pour les ajouter au groupe
5. **Ajouter un widget** : appuyer sur **+** en haut à gauche → chercher un widget (ex. : Météo, Batterie)
6. **Enlever un widget** : appuyer et maintenir sur le widget → **Supprimer le widget**
7. Appuyer sur **Terminé** (coin supérieur droit) pour quitter le mode de réorganisation

### Android

1. Appuyer sur une app et **maintenir** → les icônes passent en mode édition
2. **Déplacer une app** : glisser l'icône vers une autre position ou une autre page
3. **Créer un dossier** : glisser une app sur une autre app
4. **Ajouter un widget** : appuyer et maintenir sur une zone vide → **Widgets** → glisser le widget voulu sur l'écran
5. **Enlever un widget** : appuyer et maintenir sur le widget → **Supprimer**
6. Appuyer ailleurs ou sur le bouton **Accueil** pour quitter le mode de réorganisation

---

## Widgets recommandés

- **Météo** : voir la température et les prévisions directement sur l'écran d'accueil
- **Batterie** : voir le niveau de batterie du téléphone (et des accessoires Bluetooth sur iPhone)
