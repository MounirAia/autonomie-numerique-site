# 7.1 — Le téléphone

Le téléphone est l'une des fonctions les plus fondamentales d'un smartphone. Savoir passer et recevoir des appels est essentiel pour rester en contact avec vos proches, vos collègues et les services dont vous avez besoin. Cette section vous guidera à travers les étapes de base pour utiliser la fonction téléphone de votre appareil.

---

## Passer un appel

1. Ouvrir l'application **Téléphone**
2. Appuyer sur l'icône du clavier (pad)
3. Composer le numéro de téléphone
4. Appuyer sur le bouton vert **Appeler**
5. Pour terminer l'appel, appuyer sur le bouton rouge **Raccrocher**

> On peut aussi passer un appel depuis les **Contacts** : trouver le contact, appuyer sur son nom, puis appuyer sur le numéro de téléphone.

---

## Répondre à un appel

Quand le téléphone sonne :

- **iPhone** : glisser le bouton vert vers la droite (ou appuyer si déverrouillé)
- **Android** : glisser le bouton vert vers le haut (ou appuyer si déverrouillé)

---

## Ignorer un appel et le mettre en silencieux

Il est possible de ne pas répondre sans raccrocher brusquement :

- Appuyer une fois sur le bouton de **volume** ou le bouton **latéral** : le téléphone arrête de sonner, mais l'appel continue à se voir à l'écran
- Appuyer sur **Ignorer** ou **Rejeter** : l'appel est envoyé directement à la messagerie vocale

---

## Mettre le téléphone en silencieux

- **iPhone** : basculer le petit interrupteur sur le côté gauche du téléphone (vers le bas = silencieux)
- **Android** : appuyer sur le bouton de volume vers le bas jusqu'à l'icône silencieux, ou maintenir enfoncé le bouton d'alimentation et choisir **Silencieux**
