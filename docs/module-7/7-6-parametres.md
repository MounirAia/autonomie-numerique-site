# 7.6 — Paramètres

Les paramètres de votre smartphone vous permettent de personnaliser et de contrôler le fonctionnement de votre appareil. Vous pouvez ajuster les paramètres de son, d'affichage, de confidentialité, de notifications, etc. Savoir naviguer dans les paramètres et les modifier selon vos besoins est essentiel pour tirer le meilleur parti de votre smartphone et assurer une expérience utilisateur agréable.

---

## Changer les permissions d'une application

Certaines applications demandent l'accès à la caméra, au microphone, à la localisation, etc. Il est possible de modifier ces autorisations à tout moment.

**Sur iPhone :**
1. Réglages → faire défiler et trouver l'application
2. Appuyer sur l'application → modifier les autorisations (Caméra, Microphone, Localisation, etc.)

**Sur Android :**
1. Paramètres → Applications → choisir l'application
2. Appuyer sur **Autorisations** → modifier selon les besoins

---

## Changer les paramètres de notifications d'une application

**Sur iPhone :**
1. Réglages → Notifications → choisir l'application
2. Activer ou désactiver les notifications, choisir le style d'alerte

**Sur Android :**
1. Paramètres → Applications → choisir l'application
2. Appuyer sur **Notifications** → activer ou désactiver

---

## Changer les paramètres de localisation d'une application

**Sur iPhone :**
1. Réglages → Confidentialité → Service de localisation
2. Choisir l'application → sélectionner **Jamais**, **En cours d'utilisation** ou **Toujours**

**Sur Android :**
1. Paramètres → Applications → choisir l'application
2. Autorisations → Localisation → choisir le niveau d'accès

---

## Vérifier l'espace de stockage disponible

**Sur iPhone :**
Réglages → Général → Stockage iPhone

**Sur Android :**
Paramètres → Stockage (ou Gestion du stockage)

> Si l'espace est presque plein, supprimer des photos, vidéos ou applications inutilisées pour libérer de l'espace.
