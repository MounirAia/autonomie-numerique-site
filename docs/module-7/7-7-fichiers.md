# 7.7 — Application Fichiers

---

## Trouver et ouvrir l'application Fichiers

- **iPhone** : chercher l'application **Fichiers** (icône bleue avec un dossier) sur l'écran d'accueil ou dans la bibliothèque d'apps
- **Android** : chercher l'application **Mes fichiers** ou **Fichiers** (le nom varie selon la marque du téléphone)

---

## Trouver un fichier

1. Ouvrir l'application Fichiers
2. Naviguer dans les dossiers : **Sur mon iPhone / Sur cet appareil**, **iCloud Drive**, **Google Drive**, etc.
3. Appuyer sur un dossier pour l'ouvrir et voir son contenu
4. Appuyer sur un fichier pour l'ouvrir

---

## Trouver les fichiers téléchargés

Les fichiers téléchargés depuis Internet ou reçus par courriel se retrouvent généralement dans :

- **iPhone** : Fichiers → Sur mon iPhone → Téléchargements
- **Android** : Mes fichiers → Téléchargements

---

## Supprimer un fichier

1. Ouvrir l'application Fichiers
2. Maintenir l'appui sur le fichier à supprimer
3. Appuyer sur **Supprimer** dans le menu qui apparaît
4. Confirmer

---

## Organiser les fichiers

1. Ouvrir l'application Fichiers
2. Maintenir l'appui sur un fichier → **Déplacer** pour le mettre dans un autre dossier
3. Pour créer un nouveau dossier :
   - **iPhone** : appuyer sur les trois points (•••) en haut à droite → **Nouveau dossier**
   - **Android** : appuyer sur **+** ou les trois points → **Créer un dossier**
4. Donner un nom au dossier et confirmer
