# 6.2 — Récupérer un compte

## L'option « Mot de passe oublié »

Quand on oublie son mot de passe, il ne faut pas paniquer. Presque tous les sites offrent une façon de récupérer l'accès à son compte en quelques étapes.

---

## Étapes sur Gmail

1. Aller sur **[gmail.com](https://gmail.com)**
2. Entrer son adresse courriel → cliquer **Suivant**
3. À l'écran du mot de passe, cliquer sur **Mot de passe oublié ?**
4. Google propose une ou plusieurs options :
   - Envoyer un **code par courriel** à l'adresse de récupération
   - Envoyer un **code par SMS** au numéro de téléphone associé
   - Confirmer via un autre appareil déjà connecté au compte
5. Choisir une option → recevoir le code → l'entrer dans le champ prévu
6. Créer un **nouveau mot de passe** sécuritaire

---

## Étapes sur Outlook / Hotmail

1. Aller sur **[outlook.com](https://outlook.com)**
2. Entrer son adresse courriel → cliquer **Suivant**
3. Cliquer sur **Mot de passe oublié**
4. Choisir comment recevoir le code de vérification
5. Entrer le code → créer un nouveau mot de passe
