# 8.1 — Utilisation de Gmail

---

## Télécharger Gmail et se connecter

Si l'application Gmail n'est pas déjà installée :

1. Ouvrir le **App Store** (iPhone) ou **Google Play** (Android)
2. Rechercher **Gmail** et appuyer sur **Installer**
3. Ouvrir l'application
4. Appuyer sur **Ajouter un compte** → choisir **Google**
5. Entrer son adresse Gmail et son mot de passe
6. Suivre les étapes de confirmation

---

## Lire un courriel

1. Ouvrir Gmail — la boîte de réception s'affiche
2. Appuyer sur un message pour l'ouvrir
3. Dans un courriel, on retrouve :
   - **Expéditeur** : nom et adresse de la personne qui a envoyé
   - **Date** : quand le message a été reçu
   - **Sujet** : le titre du message
   - **Corps** : le contenu du message
4. Pour répondre : appuyer sur le bouton **Répondre** (flèche vers la gauche) en bas du message

---

## Envoyer un courriel

1. Appuyer sur le bouton **+** ou le crayon (composer)
2. Dans le champ **À** : entrer l'adresse du destinataire
3. Dans le champ **Sujet** : entrer le titre du message
4. Dans la zone de texte : écrire le corps du message
5. Appuyer sur le bouton **Envoyer** (triangle ou flèche)

---

## Ajouter une pièce jointe

Une pièce jointe est un fichier (photo, document PDF, etc.) envoyé avec le courriel.

**Avant d'appuyer sur Envoyer :**

1. Dans le courriel en cours de rédaction, appuyer sur l'icône **trombone** (en haut ou en bas de l'écran)
2. Un menu s'affiche avec plusieurs options :

| Option | Ce que ça fait |
|--------|---------------|
| **Joindre un fichier** | Chercher un fichier dans l'application Fichiers (documents, PDF, etc.) |
| **Insérer depuis Drive** | Choisir un fichier depuis Google Drive |
| **Prendre une photo** | Ouvrir la caméra directement pour prendre une nouvelle photo |
| **Joindre une photo ou une vidéo** | Choisir une photo ou vidéo déjà dans la galerie |

3. Choisir l'option souhaitée, puis sélectionner le fichier ou la photo
4. La pièce jointe apparaît dans le message avec son nom et sa taille
5. On peut ajouter **plusieurs pièces jointes** en répétant l'opération
6. Appuyer sur **Envoyer** quand tout est prêt

> **Astuce :** Si la pièce jointe est trop volumineuse, Gmail affiche un avertissement. Dans ce cas, utiliser Google Drive pour partager le fichier à la place.

---

## Naviguer dans les onglets

Gmail organise les courriels en plusieurs onglets accessibles via le menu latéral (icône trois traits) :

- **Boîte de réception** : messages reçus
- **Envoyés** : messages que vous avez envoyés
- **Brouillons** : messages commencés mais pas encore envoyés
- **Corbeille** : messages supprimés

---

## Gestes dans Gmail

| Geste | Action |
|-------|--------|
| Balayer un message vers la **gauche** | Supprimer le message |
| Balayer un message vers la **droite** | Archiver le message (retirer de la boîte de réception sans supprimer) |
| Tirer vers le bas dans la boîte de réception | Rafraîchir et vérifier les nouveaux messages |

---

## Supprimer des courriels

**Supprimer un seul message :**
- Balayer le message vers la gauche dans la liste, ou l'ouvrir et appuyer sur la corbeille

**Supprimer plusieurs messages à la fois :**
1. Maintenir l'appui sur le premier message à supprimer (une coche apparaît)
2. Appuyer sur les autres messages à sélectionner
3. Appuyer sur l'icône **corbeille** en haut

---

## Chercher un courriel

1. Appuyer sur la **loupe** en haut de Gmail
2. Taper un mot clé :
   - **Par contenu** : un mot qui se trouve dans le message (ex. : « facture », « rendez-vous »)
   - **Par expéditeur** : le nom ou l'adresse de la personne (ex. : « SAC Anjou »)
3. Les résultats correspondants s'affichent — appuyer sur un message pour l'ouvrir
