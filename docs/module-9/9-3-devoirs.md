# 9.3 — Devoirs

Dans ce devoir, vous allez pratiquer la navigation sur le web et l'utilisation de Google Maps. Ces exercices vous aideront à devenir plus à l'aise avec la recherche d'informations en ligne et la consultation de cartes pour trouver des lieux et des itinéraires.

---

## Devoir — Trouver des téléphones intelligents sur Google

1. Ouvrir le navigateur sur votre téléphone (Chrome ou Safari)
2. Faire une recherche pour trouver **3 téléphones intelligents différents à moins de 300 $**
3. Pour chaque téléphone trouvé, noter :
   - Le **nom** du téléphone
   - Le **prix**
   - Le **lien** vers la page web où vous l'avez trouvé
4. Envoyer ces informations au formateur dans **un seul courriel** via Gmail

**Exemple de présentation dans le courriel :**

> Téléphone 1 : Samsung Galaxy A15 — 219 $ — https://...
>
> Téléphone 2 : Motorola Moto G Power — 279 $ — https://...
>
> Téléphone 3 : Nokia G300 — 199 $ — https://...

**Conseils de recherche :**
- Essayer des termes comme : `téléphone intelligent moins de 300 dollars Canada`
- Les sites utiles : Best Buy, Costco, Walmart, Amazon.ca, TELUS, Fido

---

## Devoir — Trouver une pizzeria sur Google Maps

1. Ouvrir Google Maps sur votre téléphone
2. Chercher **pizzeria** dans la barre de recherche
3. Trouver la pizzeria **la plus proche** de chez vous
4. Consulter la fiche de la pizzeria et noter :
   - Le **nom** de la pizzeria
   - L'**adresse**
   - Le **numéro de téléphone**
   - La **note** (nombre d'étoiles, ex. : 4,2 / 5)
5. Envoyer ces informations au formateur dans un courriel via Gmail

**Exemple de présentation dans le courriel :**

> Pizzeria : Pizzeria Milano
>
> Adresse : 1234 rue Sherbrooke Est, Montréal
>
> Téléphone : (514) 555-1234
>
> Note : 4,3 / 5 (127 avis)
