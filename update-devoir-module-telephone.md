## Section 4: Pratiquer les gestes de base pour Smartphone et se pratiquer à écrire au clavier du téléphone
### Iphone
1. Balayer Gauche/Droite: pour changer d'écran d'accueil.
2. Balayer totalement du bas vers le haut: pour revenir à l'écran d'accueil.
3. Balayer partiellement du bas vers le haut: pour ouvrir le gestionnaire d'applications.
4. Balayer du coté haut droit vers le bas: pour ouvrir le centre de contrôle.
    - Changer la luminosité de l'écran
    - Activer/désactiver le wifi
    - Le volume du son
5. Balayer du coté haut gauche vers le bas: pour ouvrir le centre de notifications.
6. Balayer au milieu de l'écran vers le bas: pour ouvrir la recherche.
7. Appuyer sur une zone vide de l'écran d'accueil et maintenir: pour activer le mode de réorganisation des applications.
    - Déplacer une application à une autre page d'accueil
    - Selectionner plusieurs applications et les déplacer à une autre page d'accueil
    - Créer un dossier d'applications en glissant une application sur une autre application
    - Déplacer plusieurs applications dans un dossier d'applications
    - Enlever un widget de l'écran d'accueil
    - Ajouter un widget à l'écran d'accueil
      - Ajouter widget météo et batterie
8. Nettoyer l'écran d'accueil:
   - Supprimer les applications que vous n'utilisez pas du tout
   - Prendre toutes les applications que vous n'utilisez pas souvent et les déplacer à la dernière page d'accueil
   - Prendre les applications que vous utilisez le plus souvent et les déplacer à la première page d'accueil

### Android -> Avec un telphone qui n'est pas edge to edge, les gestes sont un peu différents
1. Balayer Gauche/Droite: pour changer d'écran d'accueil.
2. Cliquer sur le bouton d'accueil: pour revenir à l'écran d'accueil.
3. Cliquer sur le bouton de gestion des applications: pour ouvrir le gestionnaire d'applications.
4. Balayer du coté haut droit vers le bas: pour ouvrir le centre de contrôle.
    - Changer la luminosité de l'écran
    - Activer/désactiver le wifi
    - Le volume du son
5. Balayer encore du coté haut droit vers le bas: pour ouvrir tout le centre de contrôle.
6. Balayer du bas vers le haut: pour ouvrir la recherche de toutes les applications.
7. Appuyer sur une application et maintenir: pour activer le mode de réorganisation des applications.
    - Déplacer une application à une autre page d'accueil
    - Selectionner plusieurs applications et les déplacer à une autre page d'accueil
    - Créer un dossier d'applications en glissant une application sur une autre application
    - Déplacer plusieurs applications dans un dossier d'applications
    - Enlever un widget de l'écran d'accueil
    - Ajouter un widget à l'écran d'accueil
      - Ajouter widget météo et batterie
8. Nettoyer l'écran d'accueil:
   - Supprimer les applications que vous n'utilisez pas du tout
   - Enlever les applications que vous n'utilisez pas souvent de l'écran d'accueil (mais ne les supprimer pas, vous pouvez toujours les trouver dans la liste de toutes les applications)
   - Prendre les applications que vous utilisez le plus souvent et les déplacer à la première page d'accueil
