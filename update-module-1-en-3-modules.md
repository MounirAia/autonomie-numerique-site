# Séparer la module 1 en 3 modules
## Module 1: Introduction à Windows
1) Démarrage et fermeture
2) Interface Windows
3) Se connecter à Internet
4) Création de dossiers et de fichiers
5) Organisation des fichiers et dossiers
6) Copier, déplacer et supprimer des fichiers et dossiers
7) Utilisation de la corbeille
### Devoir
1. Étape basique de la gestion des fichiers et dossiers:
    Créer un dossier sur le bureau, le nommer "Test"
    Créer un fichier texte dans ce dossier, le nommer "Test.txt"
    Ouvrir le fichier texte, écrire "Bonjour, ceci est un test." et sauvegarder le fichier
    Renommer le fichier texte en "Test2.txt"
    Copier le fichier texte et le coller dans le même dossier, le nommer "Test3.txt"
    Supprimer le fichier "Test3.txt" et vider la corbeille
2. Dossier et sous dossier:
    1. Trouver le dossier "Photos" dans votre ordinateur
    2. Créer un nouveau dossier dans "Photos", le nommer "TestPhotos"
    3. Créer un nouveau dossier dans le "Bureau", le nommer "TestBureau"
    4. Créer un fichier texte dans "TestBureau", le nommer "TestBureau.txt"
    5. Déplacer le dossier "TestBureau" dans le dossier "TestPhotos"
    6. Télcharger une photo de votre choix sur Google, la sauvegarder dans le dossier "TestPhotos"
    7. Télecharger une deuxième photo de votre choix sur Google, la sauvegarder dans le dossier Téléchargements.
    8. Ouvrir les deux dossier ("TestPhotos" et "Téléchargements") et déplacer la deuxième photo dans le dossier "TestPhotos"
    9. Renommer les deux photos dans le dossier "TestPhotos" en "Photo1.jpg" et "Photo2.jpg"
    10. Supprimer le dossier "TestPhotos" et vider la corbeille



## Module 2: Utilisation des périphériques d'entrée (clavier et souris)
4) Pavé tactile (Touchpad)
### Devoir
1. Se pratiquer à taper au clavier
    Aller sur https://monkeytype.com/
    choisir le mode quotes
    choisir une langue (ex. : français)
    taper pendant 5 minutes, essayer de regarder le clavier le moins possible
2. Raccourcis clavier
    Objectif pratiquer: Ctrl + C (copier), Ctrl + V (coller), Ctrl + F (rechercher)

    Ok le jeu c'est un genre de jeu d'évasion.
    1. Il y a un mot de passe (base 64 string), il doive le copier aek Ctrl + C
    2. Ensuite, ils doivent le coller dans un décodeur base 64 en ligne (https://www.base64decode.org/) avec Ctrl + V
    3. Le mot de passe décodé est une URL, d'une page dans le site (/secret)
    4. C'est une page avec beacoup de texte, ils doivent trouver un mot spécifique (ex. : "Windows") avec Ctrl + F
        - Il y a plusieurs occurrences du mot, ils doivent trouver la bonne (ex. : "Windows 11.")
        - En dessous du mot, il y a un autre mot de passe (base 64 string), ils doivent le copier avec Ctrl + C
    5. Ensuite, ils doivent le coller dans un décodeur base 64 (toujours dans le site autonomie numerique)
    6. Le mot de passe décodé est une phrase: Félicitations, vous avez terminé le module 2!
